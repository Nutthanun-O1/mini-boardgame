# /ponytail - Switch Ponytail Mode

- **Khi nào dùng**: Khi muốn kích hoạt hoặc đổi cấp độ của Ponytail (lite, full, ultra, off).
- **Cách dùng**: `/ponytail [lite|full|ultra|off]`

Cấp độ hiện tại:
- **lite**: Gợi ý giải pháp lười nhất trong 1 dòng, nhưng vẫn code như bình thường nếu được yêu cầu.
- **full**: Bắt buộc áp dụng nấc thang lười (stdlib -> native -> one line -> minimum). (Mặc định)
- **ultra**: YAGNI cực đoan. Xóa trước thêm sau. Thử thách yêu cầu của người dùng.
- **off**: Tắt chế độ Ponytail.
